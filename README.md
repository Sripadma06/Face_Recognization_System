# Face Recognition-Based Attendance Management System

## Overview

The Face Recognition-Based Attendance Management System is an intelligent computer vision application developed using Python and OpenCV to automate student attendance tracking. The system detects and recognizes faces in real time, eliminating manual attendance processes and improving accuracy, efficiency, and record management.

## Features

### Student Management

* Add New Students
* Update Student Information
* Store Student Records
* Manage Student Database

### Face Recognition Module

* Real-Time Face Detection
* Face Recognition Using OpenCV
* Haar Cascade-Based Feature Detection
* Automated Identity Verification

### Attendance Management

* Automatic Attendance Marking
* Date and Time Logging
* Attendance Record Generation
* CSV and SQLite-Based Storage

### Model Training

* Face Dataset Collection
* Image Processing and Training
* Model Generation and Updating

### User Interface

* Interactive Tkinter GUI
* Easy Navigation and Data Entry
* Real-Time Attendance Monitoring
